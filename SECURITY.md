# Security Policy

## Supported versions

Security fixes are applied on a best-effort basis to the latest release on `main`.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Email **[christos.paschalidis.dev@gmail.com](mailto:christos.paschalidis.dev@gmail.com)** with:

- A short description of the issue
- Steps to reproduce, or a proof of concept if you have one
- Affected version / commit if known

I will try to respond when I can. This is a weekend project — thank you for reporting responsibly.

## Scope notes

Lock Clock uses private SkyLight / WindowServer APIs on purpose. Reports about “uses private API” or “not notarized” are known product choices, not vulnerabilities. Prefer reports that show unexpected privilege use, data exposure, or a way for another app/user to abuse the agent.
